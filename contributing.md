# Contributing

Contributions are welcome. Please submit a pull request to add, update, or remove a resource.

## Adding a Resource

- Include only resources that you have personally reviewed and would recommend to Buck2 developers.
- Confirm that the resource is maintained, documented, and not already listed.
- Add the resource to the most relevant existing section in alphabetical order.
- Use the format `- [Name](https://example.com) - Description.`
- Start the description with an uppercase letter and end it with a period.
- Describe the resource objectively without promotional language.
- Submit one resource per pull request.

## Updating or Removing a Resource

Open a pull request if a link has moved, a description is inaccurate, or a resource is no longer maintained. Explain the reason for the change in the pull request description.
